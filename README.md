# 예은의 자기소개 웹사이트

친구와 선생님에게 보여줄 수 있는 한국어 자기소개 웹사이트입니다. 친구와 함께하는 게임, 음악 듣기, 꾸준히 노력하는 점, 코딩을 배우고 싶은 마음, 학교 행사 참여, 직접 게임을 만들어 보고 싶은 목표를 소개합니다.

## 실행하기

Node.js 24 LTS를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버는 `Ctrl + C`로 종료합니다.

## 확인하기

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist` 폴더에 만듭니다. 미리 보려면 `npm run preview`를 실행합니다.

## 내용 바꾸기

- `src/App.jsx`: 자기소개 문구와 섹션 내용
- `src/App.css`: 페이지와 컴포넌트 디자인, 반응형 화면
- `src/index.css`: 전체 글꼴, 색상, 공통 스타일
- `public/`: 나중에 추가할 사진이나 작품 파일

전화번호, 주소, 생년월일 등 개인정보를 소개 페이지에 넣지 않습니다. 사진이나 작품은 직접 준비한 자료가 있을 때만 추가합니다.
